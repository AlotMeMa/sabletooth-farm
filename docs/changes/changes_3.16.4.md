# Версия 3.16.4 — полный экран после сворачивания, трофеи на своих местах

- **Полный экран ломался после сворачивания** (скрин пользователя: слева размытая полоса, справа сарай обрезан).
  Windows при возврате отдаёт обычное окно размером с монитор, а игра продолжала рисовать кадр полного экрана
  со сдвигом. Теперь сворачивание (кнопка, Alt+Tab, Win) запоминается, и при возврате полный экран
  пересоздаётся. Страховка: раз в секунду сверяется размер окна — изменился, значит пересоздать.
- **Трофеи больше не висят в воздухе и не стоят перед барменом.** Только на том, что нарисовано на фоне:
  подкова прибита гвоздём к трубе камина над свечой, кубок и золотой крестьянин — на каминной полке,
  хрустальный колос — на бочке за спиной бармена. Свои полочки и верёвочки убраны.
