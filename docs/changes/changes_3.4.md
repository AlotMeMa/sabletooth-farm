# Версия 3.4 — окна и кнопки «дерево + пергамент»

- Все окна (магазин, дерево листьев/печатей, настройки, скупщик, статистика, переезд) — деревянная рамка
  с пергаментом внутри и табличка с названием вместо синей полосы.
- Кнопки — крашеные дощечки с бликом сверху и тенью снизу (зелёные, синие, оранжевые, красные, серые).
  Любой старый цвет кнопки сам подбирает ближайший из пяти.
- Строки магазина и дерева — светлые пергаментные карточки; ручка ползунка громкости — деревянная.
- Картинки из Gemini: `assets/ui/panel`, `panel_header`, `card`, `button_<цвет>`, `slider_knob`
  (промпты — в документе «Промпты для Gemini»). Игра сама убирает фон, обрезает поля и растягивает
  картинку под любое окно и кнопку, не трогая углы. Пока картинок нет — то же самое рисуется кодом.
- Длинные строки в окне скупщика и в магазине крестьян больше не вылезают за окно.
- Номер версии в настройках — сверху слева.

## 3.4.1
- Подсветка кнопок с картинкой — мягкий свет «из-за кнопки» вместо обводки по контуру: при наведении — тёплый,
  у активной кнопки (например, «Праздник урожая») — золотой и чуть «дышит».
- Наведение больше не тормозит: раньше ореол заново считался по пикселям на каждом шаге анимации кнопки,
  теперь пятно света готовится один раз и берётся из кэша.

## 3.4.2
- Неровный край у «Праздника урожая» (и у других картинок): при удалении малинового фона тёмно-коричневый
  контур рисунка принимался за «тень на мадженте» и стирался. Теперь тень узнаётся ещё и по оттенку
  (у мадженты в тени почти нет зелёного, а в коричневом контуре есть) — контуры остаются, тени под
  грузовиками по-прежнему убираются. Заметно и на облаках, колесе загрузки, курсоре, зверях.
- Кнопки-картинки подгоняются в 128×128 (было 64) и уменьшаются при выводе — края чётче, особенно в HD.
- Все картинки один раз пересчитаются при первом запуске (новая версия кэша), загрузка будет чуть дольше.

## 3.4.3
- Кнопки внизу окон (настройки, статистика, скупщик, переезд, «С возвращением!», стрелки страниц магазина)
  подняты выше — больше не прижаты к нижней доске рамки. Окно «С возвращением!» чуть выше.
- Длинные строки в окне переезда больше не вылезают за рамку.
