# Версия 3.17 — игра на телефоне: веб-версия (iPhone и Android) и APK (23.11)

Решения пользователя: iPhone — **веб-версия** (без Mac и без $99 в год), Android — **APK через GitHub Actions**,
экран — **только горизонтально**, проверка — на iPhone.

## Где взять

- **Веб-версия:** https://alotmema.github.io/sabletooth-farm/ — собирается сама после каждого push в `main`
  (workflow `web`, ~4 минуты). На iPhone: Safari → открыть ссылку → «Поделиться» → «На экран Домой».
  С иконки игра открывается во весь экран, без адресной строки. Первый запуск качает ~25 МБ.
- **Android:** https://github.com/AlotMeMa/sabletooth-farm/releases/tag/android-latest — APK собирается сам после push
  в `main` (workflow `android`, первый раз до часа). Скачать на телефон, открыть, разрешить установку.
  Подпись — общий отладочный ключ из `mobile/android/debug.keystore`, поэтому новые версии ставятся поверх старых
  без потери сохранения. Для Google Play понадобится свой ключ.

## Что поменялось в игре

- **Пальцы** (`app.py`, раздел «3.17: пальцы»): кнопка срабатывает, когда палец *отпускают* (увёл палец с кнопки —
  ничего не нажалось); задержал палец на кнопке — подсказка над пальцем, и кнопка уже не нажмётся.
  Промах до 14 точек мимо кнопки всё равно попадает в ближайшую. Белка, ворона, разбойник, здания и ползунки
  громкости срабатывают сразу, как мышью. Монетки собираются касанием и проведением пальца по грядкам.
  Без пальца ничего не подсвечено, звука «наведения» нет. Кнопка «Назад» на Android = Esc.
- **Экран телефона** (`screen_ui.enter_handheld`): весь экран в пропорциях телефона, игра посередине, по бокам —
  размытое продолжение картинки (как полный экран 3.10). Чёткость x1.5, 30 кадров в секунду (батарея).
  В вебе: держат вертикально — «Поверни телефон»; повернули — поля подстраиваются.
- **Телефон убрали и вернули** (`App.catch_up`): если кадров не было больше 5 секунд (карман, свёрнутая вкладка),
  ферма догоняет время так же, как в офлайне, и показывает «С возвращением». Раньше время просто терялось.
  На компьютере это тоже работает (например, пока Windows держит окно).
- **Сохранение:** на Android — в личной папке приложения (переживает обновление APK); в вебе — в файл и в хранилище
  браузера (`localStorage`), при запуске возвращается оттуда (`savefile.STORE`, `savefile.restore`).
  Сохраняется и при сворачивании.
- **Ошибка на телефоне** видна прямо на экране (текст ошибки — сделать скриншот и прислать): crash.log там не достать.
- Настройки на телефоне: нет «Во весь экран»/«Края», в вебе нет «Выйти из игры»; «(M)» у звука не пишется.
- **Примерка телефона на компьютере:** `python farm_idle.py --phone` — окно в пропорциях iPhone, мышь ведёт себя
  как палец (без наведения, кнопка — по отпусканию, подсказка — если задержать кнопку мыши).

## Как устроена сборка (`mobile/`, `.github/workflows/`)

- `devtools/bake_sprites.py` — «запекает» картинки под чёткость телефона: подгоняет всё из `assets/` (как игра при
  первом запуске) и кладёт в `baked/` с `manifest.json`; фоны — JPEG. Игра, увидев `baked/`, берёт картинки оттуда
  (`spritefit.baked_sprite`), а исходники в телефонную сборку не попадают: меньше размер, и подгонка не идёт минутами
  на телефоне. Новая картинка в `assets/` → после push сборки запекут её сами.
- `mobile/build.py` — собирает папку для pygbag/buildozer (код, музыка, звуки, шрифты, `baked/`), иконку
  (крестьянин-талисман) и заставку, и дописывает в `index.html` всё для «На экран Домой».
- Веб: pygbag 0.9 (WebAssembly), главный цикл асинхронный (`App.run_async`, `main_async`), загрузка картинок —
  без потоков, с передышками для браузера (`preload_sprites_async`). Публикация — в ветку `gh-pages`.
- Android: buildozer + python-for-android v2026.05.09, Python 3.12, **свой рецепт pygame 2.6.1**
  (`mobile/android/recipes/pygame`): в p4a рецепт на pygame 2.1.0, который на новом Python не собирается,
  плюс правка kivy/python-for-android#3405 (иначе APK падает при запуске).
- `farmgame/device.py` — где запущена игра (WEB / ANDROID / примерка) и куда писать файлы.

## Проверка

Тесты (+ тест на копию сохранения в браузере), «обезьянка» на заглушке, сценарий `devtools/scenarios/phone.py`
(`python devtools/shot.py phone --phone`): тап рядом с кнопкой, увёл палец, долгое нажатие с подсказкой,
свайп по монеткам, догон 10 минут, «Поверни телефон». Веб-версия открыта в браузере в размере экрана iPhone.

## Дальше (фаза 2)

примерно 8–9 pt, читать трудно. Нужен проход по экранам со скриншотами с iPhone: крупнее шрифты, кнопки не меньше
~44 pt, окна попроще. Ещё: экспорт/импорт сохранения кодом (Safari может стереть данные сайта, если месяцами не
заходить), фразы «щёлкни» → «нажми» на телефоне.
