# Версия 3.39.6 — плитки поля одной ширины на всех фермах

Сравнение 26.11: сетка 3×3 везде одна (шаг 180×90), а картинки участков из Gemini вписывались с сохранением
пропорций и выходили разной ширины: лето 151/153, средневековье 153/166 (открытая уже закрытой — при открытии
грядка «худела»), зима 166/166, деревня 147/151 (самые большие щели между прудами). Пользователь: «да, все под 166».

- Плитки `tiles/<ферма>/soil` и `soil_locked` теперь растягиваются ровно на поле 166×94 (`align="fill"` в
  `spritefit`), как бы ни были нарисованы. Кэш пересчитается сам (правило подгонки входит в ключ).
- Остальные отличия ферм — по задумке: в деревне поле ниже на 36 px и без ограды, в пруду одна рыба.
- Сценарий `tiles_all` — по кадру поля с каждой фермы.
