# Версия 3.38.2 — лодка рыботорговца и одна рыба на участке

Решения пользователя 26.11: «Лодка точно»; «на грядках чтобы была всего одна рыба — текстура не позволяет
размещать все 3, да и меньше мельтешения». Фон с водой внизу справа пользователь уже положил в репозиторий
(дома на нём не сдвинулись — точки окон, трубы и дверей из 3.38.1 остались верными).

- **Лодка вместо повозки** (`vehicle="boat"`): «Лодка с бочкой» → «Баркас с рыбой» → «Королевский парусник».
  Приходит справа по воде и встаёт у причала; всегда покачивается на волнах, за кормой — пена, у борта блики волн,
  тени на воде нет. Уезжая, везёт ящики с рыбой. Подсказка над ней поднята выше паруса.
  Кодом (`art_fishing.draw_boat`), пока нет картинок `vehicles/boat_0..2` (или листа `vehicles/boat_sheet` 1×3,
  нос влево; холст 280×200 — с мачтой).
- Ветка дерева «Повозка» → «Лодка» («крючков от лодки»), текст главы на карте.
- **Одна рыба на участке пруда** вместо трёх — крупнее (x1.3), по центру участка.
- Сценарий `fishing_scene` снимает три лодки и уход; тест «за уловом — лодка».
