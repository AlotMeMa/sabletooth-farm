# Версия 3.27 — Игровая вместо казино, колесо фортуны, карта глав аккуратнее

## Игровая (решения пользователя 25.11)
- **Казино → Игровая.** Дверь справа в таверне ведёт в Игровую — вертикальную карту игр (как карта глав, только
  сверху вниз): листается колесом мыши, перетаскиванием, стрелками ↑/↓ и кнопками ^/v. Справа — карточка выбранной
  игры, джекпот недели и когда снова крутить колесо; слева — «В таверну» и «Призы». Открывается, как и раньше,
  со 100 жетонами. Игровая, жетоны, призы и колесо — общие для всех ферм (переезжают вместе с таверной).
- Игры по дорожке: **колесо фортуны** (сверху) → **рулетка** → **блэкджек** (скоро) → **???** (третья игра — тайна).
  Из рулетки «В игровую» / Esc — обратно в Игровую.
- **Колесо фортуны** — раз в день бесплатно (сбрасывается в полночь по часам компьютера). 8 секторов: пусто ×3,
  5, 10, 20, 50 жетонов и ДЖЕКПОТ (шансы 16/22/16/16/10/12/6/2 %). Колесо крутится ~4.6 с, щёлкает о стрелку и
  встаёт ровно на выпавшем секторе; награда начисляется сразу (закрыл окно — не пропадёт).
- **Джекпот недели** меняется каждую неделю по кругу: 300 жетонов → скин «Радужные ноты» → 500 жетонов → скин
  «Звёздный шлейф». Скины не продаются — только из джекпота (в призовой стойке видны в конце с пометкой «Джекпот
  колеса»). Скин уже есть — вместо него 250 жетонов.
  - «Радужные ноты»: ноты над бардом переливаются всеми цветами.
  - «Звёздный шлейф»: за курсором на поле — разноцветные звёздочки.
- Своё оформление (необязательно, промпты — в доке): высокая карта `ui/gameroom_map` 540×1180; лист
  `icons/gameroom_sheet` 2×3 — обод колеса `props/fortune_wheel` (сектора и надписи рисует игра — награда всегда
  точно под стрелкой), стрелка `props/fortune_pointer`, значки игр `icons/game_wheel|roulette|blackjack|secret`.
- F1 (режим разработчика) → «Колесо фортуны: снова».

## Карта глав
- Значок «СКОРО»/«ЗАКРЫТО» — над кружком главы (подпись под табличкой уезжала за нижний край карты и обрезалась).
- Глава, которая ещё в работе, — «скоро», даже если до неё две главы; в карточке: «ещё готовится, дорога — через …».
