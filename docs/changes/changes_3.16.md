# Версия 3.16 — картинки для мелочей интерфейса и эффектов (23.11)

Всё, что раньше рисовалось только кодом, теперь может брать картинки из `assets/` (без картинок — как было):

- **Доска заданий:** записки дня `ui/quest_note_1..3` (по сложности), свиток недели `ui/quest_weekly`
  (растягивается, валики — часть картинки), булавка `ui/pin`, сургучная печать `ui/wax_seal`.
- **Таблички на поле:** `ui/sign` — табличка с ценой над следующей грядкой и табличка прокачки.
- **Облачко речи** `ui/bubble` + хвостик `ui/bubble_tail`: бармен, бард, гости таверны, крупье (у крупье
  хвостик повёрнут влево).
- **Стрелка обучения** `ui/arrow` (у верхнего края экрана переворачивается).
- **Частицы** `fx/feather` (перья вороны), `fx/star` (блики), `fx/puff` (пыль, перекрашивается),
  `fx/spark` (искорки, перекрашиваются), `fx/raindrop` (капли дождя на поле и у тучки).
- **Гирлянда** в таверне (приз казино): лампочки `fx/bulb_red|yellow|green|blue` мигают по очереди.
- Листы: `ui/board_sheet` (2×3), `ui/talk_sheet` (1×3), `fx/sheet` (3×3). Нарезка листов теперь понимает
  растягиваемые элементы («trim»): кусок листа не кладётся на холст с полями.

Проверка: тесты, кадры на заглушке с пробными листами (поле, прокачка, обучение, таверна с гирляндой, доска,
казино, частицы) в HD и без, обход всех экранов. Пробные картинки в репозиторий не попали.
