# Версия 3.39.2 — помощники у грядок только на празднике, но у всех; музыка деревни

Пользователь 26.11 передумал: «сборщики по кд не стоят на грядках, но когда праздник — стоят на ВСЕХ активных
грядках вне зависимости от автосборщика. И так на всех фермах».

- Без праздника фигурок помощников у грядок нет (как до 3.39.1; у своих — только значок).
- На празднике у **каждой открытой грядки** стоит помощник — и там, где есть свой, и там, где нет:
  средневековье — крестьяне с мотыгами, зима — гномы, деревня — рыбаки (выходят из домов и уходят обратно).
- **Праздник урожая** в средневековье теперь тоже собирает урожай на всех грядках (`rush_helpers=True`, как Гномье
  пришествие и Рыбацкий фестиваль) — иначе крестьяне стояли бы «для красоты». Бот средневековья: глава 7.0 → 6.5 ч
  (половинная трата, инфляция дерева 10%) — в ряду с остальными главами (5.0 / 5.3).
- Плясунов в средневековье нет (там конфетти); тост праздника называет своих помощников («Крестьяне работают на всех
  грядках», «Рыбаки … а с уловом пляшут»), а не всегда гномов.
- Летом праздника нет (там дождь) — летних фермеров это не касается.
- Промпт музыки деревни (`assets/music/fishing.ogg`) — в доке промптов.
