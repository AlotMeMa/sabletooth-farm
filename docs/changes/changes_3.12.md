# Версия 3.12 — мельница карточками, как сарай

Живую сцену мельницы (3.7–3.11.3) убрала: картинки из Gemini рисуются каждая со своим ракурсом и не стыкуются.
Решение — **три карточки в стиле стойл сарая**: деревянная шапка, картинка на подстилке, подпись на плашке,
полоски, работники и кнопки.

- **Мельница:** горка зерна (растёт с закромами) и жернов, который крутится, пока мелют (плавно разгоняется
  и тормозит, из-под него летит мучная пыль). Полоска закромов, «Мелет $…/с (N% зерна)» или почему стоит,
  зерно на грядках, мельники (головы и −/+), «Засыпать зерно с грядок», улучшение. Клик по картинке — засыпать.
- **Мука:** мешки 1/2/3 по запасу (твои картинки), сколько муки, сколько даёт мельница и берёт пекарня,
  «Продать муку». Клик по мешкам — продать.
- **Пекарня:** печь с огнём и светом (горит ярко, пока печёт), поднос с буханками по запасу хлеба,
  полоска партии, статус, пекари, «Продать хлеб», улучшение.
- Не построено — картинка под пеленой и кнопка «Построить» (или «Сначала посади: Рожь» / «Сначала построй мельницу»).
- Карточки ниже, чем стойла в сарае: у средневековья слева четыре плашки, они больше не налезают.

Картинки, которые теперь используются: `props/millstone`, `props/grain_heap`, `props/flour_sacks_1..3`;
необязательно — `props/oven` (иначе печь кодом). `props/mill_bed` и `props/mill_hopper` больше не нужны.

Код: `farmgame/mill_ui.py` переписан (≈330 строк вместо ≈670). Проверка: тесты, кадры в HD, случайные клики
по мельнице и по всей игре — без ошибок.
