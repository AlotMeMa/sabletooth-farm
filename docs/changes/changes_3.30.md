# Версия 3.30 — экономика переездов: цены новой фермы x2

Решение пользователя 25.11 (вариант 3 из разбора): доход x2 за пройденную ферму остаётся, но и цены каждой
следующей фермы x2 (`FARM_PRICE = 2`): грядки, фермеры, крестьяне, звери, мельница, стартовые деньги и порог переезда.
Листьев за тот же «относительный» заработок дают столько же (их счёт делится на цены фермы).

Прогон бота, который играет идеально (часы до переезда):

| | лето | средневековье | зима |
|---|---|---|---|
| было (цены x1) | 7.7 | 3.8 | 1.7 |
| стало (цены x2) | 7.7 | 7.2 | 5.4 |

- Окно «Что будет при переезде»: строка «Цены там x2».
- Исправлено: перед переездом на зиму окно писало «Там: крестьяне, мельница…» (у зимы тоже артель) — теперь
  «гномье пришествие вместо дождя, мороз вместо вороны».
- Старые сохранения на средневековье: цены сразу станут x2 (деньги не меняются).
