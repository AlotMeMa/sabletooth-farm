# 3.40.4 — Быстрая загрузка, новые картинки

## Загрузка (жалоба: первый запуск «бесконечно долгий»)
Замер на этой машине (без HD): холодный запуск 524 с, тёплый 14 с. Почти всё — удаление фона в чистом Python.
- Маски фона (`bg_masks`) считаются одним проходом; с numpy — массивами. Заливка от краёв метит пиксель при
  постановке в очередь; поиск «дырок», края, рамки, крошки, обрезка — только по нужным пикселям (numpy).
  Результат побайтно совпадает со старым (сверено на 32 картинках, numpy и без numpy).
- Подгонка недостающих картинок — в нескольких процессах (`farmgame/warmup.py`, ядра − 1, до 8), по исходному
  файлу на процесс (листы и полоски целиком). Окно крутит заставку; если процессы не запустились — по-старому.
- Ключ кэша — md5 содержимого (`spritefit.digest`, индекс в `.sprite_cache/index.txt`), а не путь и дата файла:
  после clone/переноса папки/pull подгоняется только изменённое. Ответ «это полоска?» тоже хранится на диске
  (раньше считался при каждом запуске — 11 из 14 с тёплого запуска).
- Итог (2 ядра, HD 1.51): холодный ~45 с, тёплый ~1.6 с. На 4–8 ядрах холодный ожидается 15–25 с.
- Первый запуск после обновления — холодный (новый ключ кэша `fit10`).
