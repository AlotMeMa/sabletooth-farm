# Весёлая ферма

Idle-ферма на Python + pygame.

## Запуск

```
python -m pip install pygame     (или pygame-ce, если pygame не ставится)
python farm_idle.py
```

- Или просто дважды щёлкни `start_game.bat` — обычная игра, `start_dev.bat` — режим разработчика.
- `T` — таверна (открывается на средневековом поле), `Esc` — назад.
- `F11` — полный экран (то же в «Настройках»). Окно можно растягивать мышкой.
- **HD (с 3.0):** игра рисует картинку сразу в разрешении твоего экрана (на Full HD — около 1550×990
  вместо 1000×640), поэтому текст, контуры и картинки чёткие и в окне, и во весь экран. Выключить:
  «Настройки» → «Чёткость: обычная» (после перезапуска) или запуск `python farm_idle.py --hd=off`.
  Можно задать масштаб вручную: `--hd=1.5`. Размер картинки виден внизу окна «Настройки».
- `python farm_idle.py --dev` — режим разработчика: F1 открывает панель (деньги, переезд, звери, скорость времени),
  своё сохранение `farm_save_dev.json`.
- `python farm_idle.py --export-templates` — выгрузить шаблоны спрайтов в `assets_templates/`.

## Сохранение

Игра сохраняется сама каждые 15 секунд и при выходе — в `farm_save.json` (сначала во временный файл, потом
подменяет им настоящий, поэтому «полфайла» не бывает). Рядом лежат:

- `farm_save.bak.json` — запасная копия, обновляется раз в 5 минут. Если основной файл не прочитался,
  игра сама возьмёт её и скажет об этом.
- `farm_save.broken_<дата>.json` — повреждённый файл, если такой попался. Игра его не затирает: можно прислать и спасти.
- `crash.log` — если игра закрылась из-за ошибки, сюда пишется, что случилось. Пришли этот файл.

Пока игры нет, ферма работает как при открытой игре (до 3 часов, с «Большим амбаром» — дольше): грядки с фермерами
копят урожай, скотники кормят зверей, мельники и пекари работают; дождь, солнце и доход x2 из таверны идут по часам.
Вороны, разбойники и мороз в офлайне не приходят. Вернуть старое поведение (звери только доедают кормушку):
`OFFLINE_AUTOMATION = False` в `farmgame/config.py`.

## Тесты

Дважды щёлкни `run_tests.bat` (или `python -m unittest discover -s tests -t .`). Тесты проверяют логику без окна и
без pygame: офлайн, продажу фермы, таверну, чтение испорченных сохранений, обновлялку. Запускай после любых правок
в `logic.py`, `tavern.py`, `savefile.py`, `update.py` — должно быть `OK`.

## Музыка

Положи трек в `assets/music/`: `main.ogg` играет везде, а `summer.ogg`, `medieval.ogg`, `winter.ogg` — на своей ферме,
`tavern.ogg` — в таверне (можно `.mp3` или `.wav`). Музыка играет по кругу и плавно меняется при переезде.
Громкость музыки и звуков кнопок — ползунки в «Настройках», клавиша `M` — выключить/включить весь звук.
Звуки игры встроены (игра синтезирует их сама). Любой можно заменить своим файлом `assets/sfx/<имя>.ogg` (или .wav/.mp3):

| Имя | Когда звучит |
|---|---|
| `hover` | наведение на кнопку |
| `click` | нажатие кнопки |
| `coin` | сбор урожая с грядки |
| `coin_big` | гигантский урожай x10, пойманная белка |
| `buy` | покупка (уровень грядки, зверь, здание, крестьянин...) |
| `levelup` | веха грядки, улучшение в дереве |
| `product` | сбор продуктов сарая, хлеба, продажа муки |
| `feed` | покормить зверей / засыпать зерно |
| `squirrel` | белка выбежала на луг |
| `crow` | ворона села на грядку |
| `shoo` | прогнать ворону или разбойника |
| `bandit` | разбойник крадётся |
| `truck` | приехал грузовик скупщика |
| `fanfare` | приехал сборщик податей, переезд, праздник урожая |
| `rain` | дождь |
| `sun` | солнечный бонус |
| `sell` | продажа фермы скупщику |
| `quest` | задание таверны выполнено |
| `claim` | награда за задание получена |
| `crowd` | гул голосов в таверне (фон, играет по кругу; громкость — ползунок «Звуки») |

Бесплатная музыка: OpenGameArt (фильтр CC0), Pixabay Music, itch.io (тег music + CC0).
Если лицензия CC-BY — укажи автора в титрах.

## Таверна и доска заданий

Открывается на средневековом поле: кнопка «Таверна» слева, над «Магазином» (или клавиша `T`).
Таверна общая для всех ферм — задания, прогресс и жетоны не сбрасываются ни продажей фермы, ни переездом.

- Стрелка слева — **доска заданий**: 4 задания на день (★ лёгкое, ★★ два средних, ★★★ трудное),
  обновляются в полночь по часам компьютера. Справа — **задание недели**, обновляется в ночь на понедельник.
- Награды: деньги (15/25/40 минут дохода грядок — считается в момент получения) и **жетоны таверны**.
  Выполнил, но не успел забрать до полуночи (или до понедельника)? Награда не сгорает — игра выдаст её сама.
  Задание недели: 3 часа дохода, 60 жетонов, 15 печатей/листьев и доход x2 на 30 минут.
- Жетоны пока копятся — на них будут казино (дверь справа) и скины.
- Бармена и барда можно щёлкать — они разговаривают.
- Свой фон зала (`assets/backgrounds/tavern`) и доски (`quest_board`) — см. раздел «Таверна» в `SPRITES.md`.
  Там же — как сдвинуть бармена, барда и «стойку перед ними» файлом `backgrounds/tavern.json`, не трогая код.
- Если после переезда задание стало невыполнимым (например, разбойников на новой ферме нет), оно заменится.

## Экран загрузки

Пока игра подгоняет картинки, крутится деревянное колесо с талисманом-крестьянином, сверху — логотип.
Свои картинки: `assets/ui/logo`, `assets/ui/loading_ring` (колесо), `assets/ui/loading_center` (талисман),
`assets/backgrounds/loading` (фон) — подробности в `SPRITES.md`, раздел «Экран загрузки». Без них всё рисует код.

## Шрифт

Свой шрифт кладётся в `assets/fonts/` (`.ttf` или `.otf`, нужна кириллица). Если файлов два, игра сама разберёт:
`...-Black` / `...-Heavy` — для надписей с обводкой (кнопки, заголовки, цифры на поле), `...-ExtraBold` / `...-Bold` —
для обычного текста. Один файл — он для всего. Размер подгоняется по ширине под прежний шрифт, поэтому надписи
не вылезают из кнопок. Нет файлов — системный шрифт, как раньше. Сейчас в игре — Nunito (Google Fonts, лицензия OFL).

## Настройки

Три вкладки: **Звук** (громкость музыки и звуков, выключить звук), **Экран** (окно / весь экран, чёткость HD,
ограничение кадров 30 / 60 / 144, счётчик кадров в углу), **Игра** (статистика, подсказки у кнопок, сохранить,
сбросить всё). Подсказка появляется, если задержать курсор на кнопке или плашке на полсекунды.

## HD-режим: как устроен

Логика и разметка игры по-прежнему в координатах 1000×640, а `farmgame/hd.py` подменяет «холст»: всё
рисуется в k раз крупнее (k подбирается так, чтобы окно влезло на экран; не больше 2). Картинки из `assets/`
подгоняются под этот размер и кладутся в `.sprite_cache/` отдельно для каждого k — поэтому первый запуск
после включения HD (или после смены монитора) дольше, потом всё мгновенно. В Windows с масштабом 125%/150%
игра теперь просит у системы настоящие пиксели, и окно не размывается.
Если игра в HD тормозит: «Настройки» → «Чёткость: обычная». Скорость (кадры в секунду) видна в режиме
разработчика, в панели F1.

## Обновление (твои картинки и прогресс не теряются)

1. Положи архив с новой версией (`.zip`) в папку с игрой.
2. Дважды щёлкни `update.bat` (или перетащи архив прямо на него) и нажми Enter.

Скрипт сохранит старый код и сохранения в `_backup/<дата>_v<версия>/` и заменит только код.
`assets/`, `farm_save*.json`, `.sprite_cache/` и `_backup/` он не трогает никогда. Если при обновлении
что-то пошло не так, он сам вернёт старую версию. Откатиться вручную: скопируй файлы из нужной папки
`_backup/` обратно в папку игры. Версия игры видна в окне «Настройки» и в заголовке окна.

Архивы обновлений не содержат папку `assets/`, так что даже распаковка поверх папки игры ничего твоего не сотрёт.

## Что где лежит

| Файл / папка | Что внутри |
|---|---|
| `farm_idle.py` | точка входа — запускай его |
| `farmgame/config.py` | баланс и данные: культуры, цены, звери, деревья улучшений, фермы |
| `farmgame/logic.py` | логика фермы (класс `Farm`) — без графики |
| `farmgame/art.py` | вся графика: загрузка спрайтов и рисунки кодом |
| `farmgame/app.py` | окно, ввод, экраны и окна интерфейса |
| `farmgame/templates.py` | выгрузка шаблонов спрайтов |
| `farmgame/tavern.py` | задания таверны: генерация, прогресс, награды (без графики) |
| `farmgame/tavern_ui.py` | таверна на экране: зал, бармен, бард, доска заданий |
| `farmgame/mill_ui.py` | экран мельницы и пекарни: живая сцена, карточки внизу (3.7) |
| `farmgame/tutorial.py`, `farmgame/tutorial_ui.py` | обучение на первой ферме: шаги (без графики) и бармен на экране (3.9) |
| `farmgame/audio.py` | музыка и звуки (встроенный синтез + свои файлы) |
| `farmgame/savefile.py` | запись сохранения, запасная копия, спасение повреждённого файла |
| `farmgame/anim.py`, `farmgame/particles.py` | плавность (кривые движения) и частицы: монетки, искорки |
| `farmgame/skin.py` | оформление окон и кнопок «дерево + пергамент»: картинки из `assets/ui/` растягиваются без искажения углов |
| `farmgame/screenfit.py` | полный экран без чёрных полос: размер окна и сдвиг картинки (3.10) |
| `farmgame/hd.py` | HD-режим: холст в k раз крупнее, подмена рисования, выбор масштаба под экран |
| `tests/`, `run_tests.bat` | тесты логики (без pygame) |
| `farmgame/spritefit.py` | автоподгонка картинок: убрать фон, обрезать, вписать в размер |
| `assets/` | твои картинки (PNG/JPG). Инструкция — `SPRITES.md` |
| `start_game.bat`, `start_dev.bat` | запуск игры / режима разработчика двойным щелчком |
| `update.bat`, `update.py` | обновление игры без потери файлов |
| `_backup/` | бэкапы старых версий и сохранений (последние 10) |
| `assets_templates/` | шаблоны: каждый объект в нужном размере |
| `farm_save.json` | сохранение (появится после первого запуска); `farm_save.bak.json` — запасная копия |
| `.sprite_cache/` | подогнанные картинки (можно удалять — пересчитаются) |

Сохранение от прошлой версии подхватится, если положить новую версию в ту же папку.
