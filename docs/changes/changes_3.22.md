# Версия 3.22 — огонь виднее и спокойнее

- Огонь у камина горит **перед поленьями**: за ними его было почти не видно. У самых углей языки ещё тусклые,
  поэтому поленья просвечивают и кажутся охваченными огнём, а не закрашенными.
- Огонь **медленнее и плавнее**: языки поднимаются в 2–3 раза дольше (скорость 80–125 вместо 170–260 px/с,
  жизнь 1.1–2.0 с), покачиваются и мерцают втрое реже, рождается их меньше — пламя не пересвечивается в белое.
- Огонь чуть крупнее (`fire_w` 185, `fire_h` 235).
- `FIRESIDE_CUSTOM["front"]` теперь пуст: многоугольники фона поверх огня по-прежнему поддерживаются, если понадобятся.
