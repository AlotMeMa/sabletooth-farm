# 3.45.5 — Заставка главы при переезде

- После переезда на 3.4 с — заставка: «Глава N» и название поверх картинки главы, плавное появление, лёгкий наезд
  камеры и затухание в новое поле. Щелчок — пропустить. Картинка — `backgrounds/chapter_<глава>` (промпт в доке
  промптов, раздел «Заставки глав»); пока её нет — притемнённый фон поля новой главы. Сценарий — `chapter_card`.
- Первый шаг плана «красивый переход между локациями»; следующий — карта глав плитками (`ui/move_map_<глава>`),
  когда придут картинки.
