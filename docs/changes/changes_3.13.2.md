# Версия 3.13.2 — правки по скриншотам

1. **Плашки бонусов не налезают на карточки.** «Доход x2» и песня барда на поле — слева столбиком, как раньше;
   в сарае, мельнице и таверне — справа под шестерёнкой.
2. **«Доска заданий» в таверне** подсвечивается по форме стрелки (тёплый свет и ореол), а не квадратной рамкой.
3. **«Макс. уровень»** (сарай, мельница, пекарня) и «Все наняты» (крестьяне) — золотая дощечка со звёздами
   вместо плоского жёлтого прямоугольника (`skin.draw_max`).
4. **Каменная стена у грядок** средневековья — новая кладка кодом: тёмный раствор, два ряда скруглённых камней
   разного размера и оттенка, плоские камни сверху, кое-где мох (`art.draw_stone_wall`). Рисуется один раз
   и берётся из памяти — кадры не тратятся. Своя картинка `props/medieval/fence_strip` по-прежнему главнее.
5. **Крестьянин в магазине не мыльный.** Крупные иконки берутся из вдвое более крупной подгонки (`name@2x`,
   `art.blit_icon`): раньше иконку 40×40 растягивали в 2.2 раза.
