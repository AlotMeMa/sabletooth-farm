# Версия 3.33 — призовая стойка по полочкам и новые призы

Просьба пользователя 25.11: «в магазине поменяй местами трофеи и украшения, а сами украшения разбей на вкладки
украшений, персонажей, эффектов и всего прочего, иначе снова всё в одной куче»; «больше скинов, больше трофеев».

## Вкладки
`config.PRIZE_TABS`: **Украшения · Персонажи · Эффекты · Прочее · Трофеи** (трофеи — последние, открывается
вкладка «Украшения»). У косметики поле `cat` (decor / chars / fx / misc). Не продающиеся (джекпот колеса,
за достижения) — в конце своей вкладки.

## Группы «одно из»
Поле `group`: включил одно — остальные из группы выключились (`Tavern._one_on_stage` обобщён, `Tavern.group_on`,
`tavern.prize_group`). Группы: `stage` (артисты сцены, как раньше), `trail` (шлейф курсора), `notes` (ноты барда),
`cards` (рубашка карт). Выпавший джекпот колеса сразу включается.
