# Версия 3.16.7

- **Кнопка «Призы» прямо в таверне** — слева над «На поле» (как «Таверна» над «Магазином» на поле).
  Открывает призовую стойку без похода в казино. Красный «!» — когда жетонов хватает хотя бы на один приз.
  Своя картинка — `ui/btn_prizes` (квадрат), без неё деревянная плашка с жетоном в тон остальным кнопкам.
