# 3.45.3 — Окна закрываются щелчком мимо; аквариум без «купил-продал»

- **Щелчок мимо окна закрывает его** (просьба пользователя): Магазин, Крючки/Листья, Настройки, Переезд, Достижения,
  Призы, Статистика, Песни, Колесо фортуны, «С возвращением», грузовик. Щелчок по затемнённому фону = крестик.
  Не закрывается: пока окно выезжает (защита от двойного щелчка) и пока крутится колесо. Садки, таверна и Игровая —
  отдельные экраны, не окна, у них по-прежнему кнопка «назад». Своё исключение — в `KEEP_OPEN` (`app.py`).
  Как работает: `panel()` запоминает рамку окна с табличкой и крестиком (`panel_hit`), `click_away()` в `on_click`.
  Проверка — сценарий `clickaway`.
- **Аквариум:** продать можно только взрослую рыбку; щелчок по мальку — «растёт N%», подсказка — сколько будет
  стоить взрослой. Покупка вычитается из заработка забега полностью (раньше — не ниже нуля: при деньгах больше
  заработка, например со стартовым капиталом, купил-продал добавлял крючки из воздуха).
- `ui/btn_fishery` теперь в списке известных картинок (не было предупреждения «не узнаю»).
