# Версия 3.34.2 — своя медаль у каждого достижения (заготовка под картинки)

Решение пользователя 25.11: медали достижений — «своя у каждого» (42 значка).

- Картинки: `icons/ach_<id достижения>` (холст 96×96, рисуется в 0.5 → ~48 px в строке окна). Пять листов 3×3:
  `icons/ach_sheet_1` … `icons/ach_sheet_5`, порядок клеток — как в `achievements.ACHIEVEMENTS`
  (`spritefit.ACH_SHEET_ORDERS`), в пятом листе последние три клетки — запас. Отдельный файл важнее клетки.
- Не выполненное достижение показывает свою медаль бледной (прозрачность 85); без картинки — медаль кодом, как раньше.
- Промпты пяти листов — в доке промптов, раздел «Медали достижений».
