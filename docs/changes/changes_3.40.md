# 3.40 — Скачки улиток

Третья игра Игровой вместо «???». Открывается в Рыбацкой деревне (до неё на карте — «В ДЕРЕВНЕ»).

## Как играть
- Ведёт моряк **Старый Якорь**: седой, одноглазый, с трубкой и кружкой, травит байки про море (щёлкни по нему).
  При первом заходе рассказывает правила (3 реплики), кнопка «?» — правила ещё раз.
- Пять улиток: Молния, Ракушка, Тихоня, Слизень Вася, Бабушка Улита. Перед каждым забегом новые шансы
  и коэффициенты (справа на табло), у кого-то настроение «в ударе» или «сонная».
- Щёлкни по дорожке — выбрать улитку, ещё раз — добавить фишку (5/10/25/50, ставка от 5 жетонов).
- «Старт!» → «На старт… Марш!» → улитки ползут сами (~10 с). Итог объявляется, когда доползает первая;
  остальные доползают, у каждой медалька места.
- Выигрыш = ставка × коэффициент. Возврат игроку ≈ 95% (как у рулетки), коэффициент не ниже x1.2.
- «Ещё забег» — новые шансы, ставка на ту же улитку. Ушёл до старта — ставка возвращается.

## Достижения (лист медалей 7)
- «Болельщик» — посмотри 30 забегов.
- «Тёмная лошадка» — выиграй на улитке с коэффициентом от x8.

## Прочее
- Блокировка игр Игровой обобщена: `unlock="winter"` / `unlock="fishing"`.
- Режим разработчика, вкладка «Игровая»: открыть улиток, правила снова, следующий забег — победа/проигрыш.
- Картинки (необязательно): `characters/sailor` (по пояс, 150×150, низ = край стола), `characters/snail_1..5`
  (смотрят вправо), `icons/game_snails`, `icons/ach_sheet_7`. Без них всё рисуется кодом.
- Тесты: `tests/test_snails.py` (шансы, RTP, порядок финиша, оплата, возврат, сохранение, медали).
- Сценарий: `devtools/scenarios/snails.py`.
