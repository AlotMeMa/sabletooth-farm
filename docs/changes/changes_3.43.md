# 3.43 — Кости «Больше / меньше / 7» (откроются в главе 5)

Ответы пользователя на тест 27.11: делаем игру в кости; правила «больше / меньше / 7»; ведёт юная драконица;
в главе 5 растут огненные растения (это — на потом).

- Новая игра Игровой под скачками улиток: «Кости», открывается в горной деревне драконов (`unlock="dragons"`,
  на карте — «В ГОРАХ»). Главы 5 ещё нет: сыграть можно из F1 → «Игровая» → «Кости: открыть (глава 5)».
- Ведёт **Искра** — юная драконица (коралловая чешуя, рожки, крылышки, хихикает искорками). Правила в 3 репликах,
  щелчок по ней — болтовня, «?» — правила снова.
- Две кости. Поля: «Меньше 7» (2–6) x2.3, «Ровно 7» x5.7, «Больше 7» (8–12) x2.3 — возврат ≈95%, как у рулетки
  и улиток. Фишки 5/10/25/50, можно на несколько полей; на поле видно, чем кончится, если выпадет оно.
- «Бросить!» — кости вылетают из лап Искры, кувыркаются и катятся по сукну (~1.4 с), выигравшее поле светится,
  итог — чистыми. «Ещё бросок» — те же ставки. Слева — последние суммы.
- Медали (лист 7): «Кости брошены» (50 бросков), «Счастливая семёрка» (выигрыш на «Ровно 7»).
- Картинки по желанию: `characters/dragoness` (по пояс, 150×150, низ = край стола), `icons/game_dice`.
- Логика `farmgame/dice.py`, экран `farmgame/dice_ui.py`, тесты `tests/test_dice.py`, сценарий `dice`.
