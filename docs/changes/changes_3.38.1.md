# Версия 3.38.1 — живой фон Рыбацкой деревни

Фон деревни из Gemini — `assets/backgrounds/fishing.jpg` (пользователь закоммитил 26.11, «картинки»):
точки окон, трубы и дверей привязаны к этой картинке).

- **Пруд ниже** на 36 px (`THEME["field_dy"]`, общий сдвиг через `FIELD_DY` / `grid_oy()` — клетки, клики,
  забор): верхний угол больше не задевает море. У других ферм сдвиг 0.
- **Без забора** в деревне (`THEME["fence"]=False`): у прудов свои сетки с поплавками.
- **Окна мерцают** тёплым светом очага — у каждого окна свой ритм (хижина справа, дом наверху, хижина слева).
- **Дым** из трубы дома наверху — клубы поднимаются и сносятся ветром вправо.
- **Рыбацкий фестиваль:** рыбаки выходят из трёх домов (каждый — из ближнего к своему пруду), идут к прудам и встают
  с удочками; двое с уловом идут плясать — между прудом и хижинами. В конце фестиваля все расходятся по домам.
  Рыбаки в пути рисуются поверх прудов.
- Всё это включается, только если лежит именно эта картинка фона (`THEME["scene"]`); без неё — как в 3.36
  (рыбаки выскакивают с брызгами).
- Сценарий `fishing_scene`, тесты точек сцены в `tests/test_fishing.py`.

Открытый вопрос: покупатель (повозка) въезжает справа по низу экрана — на этом фоне там причал с бочками и лодкой.
Ждём решения: дорога внизу справа (повозка) или вода у причала (лодка вместо повозки).
