# Версия 3.21 — новый огонь, трофеи у огня, зал без кота

## Огонь у камина
- Плоские языки-многоугольники заменены живым огнём из частиц: мягкие вытянутые пятна рождаются на углях,
  поднимаются, сужаются к середине и остывают (белое-жёлтое ядро → оранжевый → красный → тают).
  Пятна кладутся «светом» (смешивание BLEND_RGB_ADD): где языков много, огонь раскаляется, края мягкие.
- Огонь не поднимается выше своего верха (раньше отдельные искры света уходили на стену над аркой).
- «Подбросить полено» — огонь гуще и выше на несколько секунд.

## Таверна
- **Трофеи** больше не стоят в зале: они на каминной полке в «посиделках у камина» (подкова — на трубе).
- **Кот** — только у огня (в зале убран).
- **Ваза с цветами** в зале крупнее и стоит на столе между кружками.
- Реплика бармена про трофеи зовёт к камину.
