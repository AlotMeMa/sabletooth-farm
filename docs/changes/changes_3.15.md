# Версия 3.15 — разбор app.py (для игрока ничего не меняется)

`farmgame/app.py` был 2824 строки — один класс App на всё. Теперь в нём ядро (711 строк), а остальное —
модули-примеси по смыслу, как уже были таверна, мельница, обучение и казино:

| Модуль | Что внутри |
|---|---|
| `field_ui.py` (FieldUI) | поле: грядки, сбор, покупки, солнце, дождь, праздник, грузовик, режим прокачки |
| `creatures_ui.py` (CreaturesUI) | белка, ворона, разбойник, мороз и лёд |
| `barn_ui.py` (BarnUI) | сарай: стойла, покупки зверей, фон сарая и мельницы |
| `windows_ui.py` (WindowsUI) | окна: магазин, дерево, крестьяне, скупщик, настройки, статистика, переезд, офлайн, разработчик |
| `hud_ui.py` (HudUI) | плашки сверху, кнопки снизу, шестерёнка |
| `widgets_ui.py` (WidgetsUI) | кнопки, окна-панели, подсказки, сообщения, зоны клика |
| `screen_ui.py` (ScreenUI) | окно, HD, полный экран без полос, курсор |
| `ui_common.py` | общие импорты и константы (раньше — шапка app.py) |

`class App(TavernUI, MillUI, TutorialUI, CasinoUI, FieldUI, CreaturesUI, BarnUI, WindowsUI, HudUI, WidgetsUI, ScreenUI)`.

Как делалось: методы перенесены скриптом по синтаксическому дереву — текст байт в байт, логика не тронута.
Правило на будущее: **имена методов в разных примесях не должны совпадать** (в 3.11 так ловили `draw_wheel`).

Проверка:
- нет одинаковых имён методов в разных классах; нет неопределённых имён (symtable по всем модулям);
- 85 тестов;
- 33 кадра игры в HD (поле, сарай, мельница, таверна, доска, казино, песни, обучение, окна) **попиксельно совпадают** до и после;
- случайные клики: обычный режим, HD, режим разработчика, казино — без ошибок;
- отдельный агент-ревьюер (не видевший работу) проверил перенос: см. ниже.

### Что нашёл агент-ревьюер (и что сделано)
Серьёзного не нашёл: сравнил по синтаксическому дереву все 140 членов старого App с новыми модулями —
ничего не потеряно, тексты совпадают; нет `super()`/`type(self)`/приватных имён, которые сломались бы при
переносе; внешний код (devtools, tests, templates) работает; циклических импортов нет. Мелочи — исправлены:
- атрибуты класса `MONEY_ICON`, `FESTIVAL_RECT` (→ FieldUI), `BANDIT_STEP` (→ CreaturesUI),
  `SETTINGS_TABS` (→ WindowsUI) переехали к методам, которые ими пользуются;
- убраны лишние пустые строки в app.py и неиспользуемый импорт `_rain_*` в новых модулях.
Оставлено как есть: `build_mill_background` — в barn_ui (экран мельницы — это вид «сарай» средневековья).
После правок все проверки повторены: 33 кадра снова попиксельно совпадают, тесты и случайные клики — без ошибок.
