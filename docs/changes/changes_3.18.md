# Версия 3.18 — картинки для плашек, сообщений, баннеров, полосок и указателей таверны (24.11)

Ещё четыре вещи, которые рисовались только кодом, теперь могут брать картинки (без них — как было):

- **Плашки счёта** `ui/pill`: деньги, доход, печати/листья, крестьяне, жетоны, «доход x2», песня барда, бафы казино.
- **Сообщения** `ui/toast`: плашка сообщений внизу экрана.
- **Баннер** `ui/banner`: «РЕЖИМ ПРОКАЧКИ» (крестик сдвигается за конец ленты), «САРАЙ», «МЕЛЬНИЦА».
- **Полоски прогресса** `ui/bar_frame` + `ui/bar_fill` (белая, красится в цвет полоски) — везде, где `draw_bar`.
  Заливка не пересчитывается каждый кадр: рисуется кусок готовой полоски и её закруглённый конец.
- **Указатели таверны** `ui/sign_board` (стрелка «Доска заданий») и `ui/sign_casino` (вывеска «Казино»).
- Лист `ui/plate_sheet` (2×3): pill, toast, banner; bar_frame, bar_fill, sign_casino.

Проверка: тесты, кадры на заглушке с пробным листом (поле, прокачка, сарай, мельница, таверна, доска),
обход всех экранов в HD и без. Пробные картинки в репозиторий не попали.

## 3.19.1 — плашки и полоски из листа пользователя (24.11)
- Gemini нарисовал `ui/plate_sheet` сеткой 3×2 вместо 2×3 и вместо белой заливки полоски — вторую ленту,
  поэтому нарезка листа давала двухслойные плашки и тёмные полоски. Лист разрезан вручную на отдельные файлы
  `ui/pill`, `ui/toast`, `ui/banner`, `ui/bar_frame`, `ui/sign_casino`; белая `ui/bar_fill` собрана по форме
  середины рамки. Отдельные файлы важнее листа — `plate_sheet` у пользователя больше не используется.
- Лента-баннер режется на 3 части с широкими краями (концы-«хвосты» не растягиваются); заливка полоски
  отступает от края рамки на 15% высоты (под толщину её деревянного края).
