# Версия 3.25 — гномы и оттепель для зимы, карта и артисты из картинок

## Зима (глава пока закрыта)
- **Помощники — гномы** (решение пользователя): работают как крестьяне в средневековье — общая артель, нанимаешь
  в магазине («Гномы» → «Нанять гнома»), ставишь на грядки, они растят и копят урожай. Мельницы нет — только грядки.
  Значок — гном в красном колпаке (`icons/gnome`, без картинки — кодом). Задания таверны тоже про гномов
  («Найми 3 гнома»).
- **Оттепель вместо праздника урожая:** кнопка, как «Праздник урожая» (`ui/btn_thaw`, без картинки — солнышко с
  каплей), на месте летней тучки. Во время оттепели — тёплый свет и падающие капли-искорки, звук солнечного бонуса.

## Картинки пользователя
- **Карта глав** `ui/move_map`: кружки глав стоят на нарисованных полянках, своя дорожка кодом на ней не рисуется.
- **Скрипач Тимоха** и **волынщик Ерёма** на сцене — картинками.

## Для разработки
- `config.HELPERS` (названия и формы помощников, значок), `FARMS[...]["helpers"]`; `App.helpers()`;
  `art.draw_helper_head` (крестьянин или гном), `FARM_INDEX`.
- `config.WEATHER_BUTTON` — погода кнопкой (праздник, оттепель); `draw_festival_button(kind)`.
- Тесты в `test_winter.py`: гномы, оттепель, текст задания.
