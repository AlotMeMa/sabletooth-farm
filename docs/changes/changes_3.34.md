# Версия 3.34 — достижения и разговоры с барменом

Просьба пользователя 25.11: «косметика и общение с барменом; больше скинов, больше трофеев и достижений».

## Достижения (`achievements.py`, окно — `achievements_ui.py`)
- 42 достижения в 4 разделах: **Поле** (урожай, уровни, вехи, белки, вороны, разбойники, солнце, погода),
  **Хозяйство** (продажи, дерево, заработок за всю игру, главы, сарай, хлеб, помощники), **Таверна** (задания,
  песни, разговоры с барменом, призы, кот, пёс, камин), **Игровая** (колесо, рулетка, блэкджек).
- Счётчики событий — `Tavern.stats` (общие для всех ферм, считаются с начала игры, даже пока таверна закрыта;
  каждое событие `App.quest(...)` попадает туда). Новые события: `song`, `barman_talk`, `pet_cat`, `pet_dog`,
  `fire_poke`, `wheel_spin`, `wheel_jackpot`, `roulette_spin`, `roulette_number`, `bj_win`, `bj_natural`.
- Старые сохранения: продажи ферм (`prestiges`) и выполненные задания (`daily_done_total`) засчитываются.
- Награда — жетоны (5–100), медаль бронза/серебро/золото по размеру награды. Два трофея только за достижения:
  **Золотая белка** (100 белок) и **Золотые вилы** ($1aa за всю игру) — сразу висят на трубе камина.
- Проверка раз в секунду; выполнено — тост и звук; жетоны — кнопкой «Забрать» / «Забрать всё».
- Где: «Настройки» → «Игра» → «Достижения» (рядом со «Статистикой»), и кнопка в таверне над «Призами»
  (с «!», когда есть награда; своя картинка — `ui/btn_achievements`).

## Бармен Гаврила (`barman_talk.py`)
- Щелчок по бармену — темы на стойке: **«Как дела?»** (по времени суток на часах ПК), **«Что нового?»** (награды
  на доске, ближайшее задание, задание недели, колесо фортуны, новые достижения, песня), **«Дай совет»** (по делу:
  листья, жетоны на призы, свободные помощники; иначе общий), **«Расскажи историю»** (12 историй по порядку:
  прадед и король, «Хмельной колос», кривозубый крестьянин, золотая белка, разбойники и плясовая, Мила, Ерёма,
  гномы севера...). «Пока!» закрывает.
- Длинный ответ — облачко шире (до 7 строк) и висит дольше.
