# Версия 3.19 — посиделки у камина, магазин таверны только для красоты

## Посиделки у камина
- Наведи на камин в таверне — он подсвечивается. Клик — садишься у огня.
- Огонь живой: языки пламени качаются, тлеют угли, летят искры. Клик по огню — «подбросить полено»:
  пламя вспыхивает, искры летят столбом, слышен треск.
- Звук: музыка таверны тихо (около трети громкости), гул зала громче, сверху треск поленьев.
  Треск синтезирован; настоящая запись — `assets/sfx/fire.ogg` (подхватится сама).
- Ферма работает как обычно: это место, где можно оставить игру вместо паузы. Внизу видно,
  сколько ферма заработала, пока сидишь (если на грядках есть работники).
- Плашек денег нет, сообщения — сверху. «Встать», Esc или T — назад.
- Без своей картинки фоном служит камин из зала таверны крупным планом, приглушённый, с тёмными краями.

## Магазин таверны — только украшения
- «Счастливая монета» и «Клевер» убраны: покупки за жетоны больше не влияют на доход и удачу.
  Старые сохранения читаются (таймеры просто больше ни на что не действуют).
- Вкладки «Трофеи» и «Украшения», товары по цене, листаются по 4 («<» / «>»).
- Новые украшения: полевые цветы (60), коврик у огня (90), котелок над огнём (120), кот у камина (150).
  Цветы — на столе и на каминной полке, котелок булькает над огнём и пускает пар,
  кот спит у очага (у камина его можно погладить). Коврик виден, когда сидишь у огня.
- Песни барда не тронуты: это не магазин, а заказ на время.

## Для разработки
- `Sfx.ambients({имя: громкость})` — несколько фоновых петель сразу (гул + камин); `Music.scene_k` —
  приглушение музыки в сцене, ползунок громкости не меняется.
- Новые файлы: `fireside_ui.py` (FiresideUI), `fireside_art.py`; сценарий кадров `devtools/scenarios/fireside.py`.
- Тесты `tests/test_fireside.py`: у каждого приза есть значок кодом, каждое украшение где-то рисуется,
  петля камина без щелчка на стыке.
