# Версия 3.16.1 — трофеи в таверне, певица Мила, новые ноты в меню песен

- **Трофеи казино стоят в таверне** (решение автора: «так интереснее»), а не на полке в казино:
  подкова висит на трубе камина над свечой, золотой крестьянин и серебряный кубок — на каминной полке,
  хрустальный колос — на маленькой полочке на стене справа от трубы. Купленные чуть светятся, у каждого
  подсказка. Места — `trophies` в разметке таверны (`tavern.json` может переопределить).
  Полка в казино убрана, крупье теперь говорит «Трофеи украсят таверну».
- **Новый приз — «Певица Мила»** (украшение, 300 жетонов, вкл/выкл): на сцене вместо барда крестьянка
  с лютней, со своими репликами. Её песня — `assets/music/tavern_girl.ogg` (нет файла — поёт под обычную
  музыку таверны); темп её трека — `music_girl` в разметке (пока как у таверны). Картинка —
  `characters/bard_girl` (как бард: 130×180, низ = сцена), значок — `icons/prize_bard_girl`.
  Промпты и описание песни — в доке «Промпты для Gemini», раздел «Таверна: певица Мила».
- **Окно «Заказать песню» и плашка песни** рисуют ноты из картинок `icons/note_1..4`, как в зале.
- Лист призов 3×3 по-прежнему берёт первые 9 призов; новые призы — отдельными файлами.
