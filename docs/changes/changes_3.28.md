# Версия 3.28 — блэкджек с рыжим гномом Ворчуном

Решения пользователя 25.11: блэкджек открывается **только зимой** (с главы «Зимнее поле»), дилер — **новый
персонаж: рыжий гном, бормотун, вечно недовольный**, **упрощённые правила**, игра против дилера, **без удвоения**.

- В Игровой у блэкджека значок «ЗИМОЙ» и замок, пока ты на летней ферме или в средневековье. Зимой — садишься за стол.
- Правила: ставка жетонами от 5, без лимита; по 2 карты, вторая карта дилера закрыта; «Взять» — ещё карта,
  «Хватит» — ход дилера (берёт, пока меньше 17); туз — 1 или 11, картинки — 10; перебор — проигрыш;
  выигрыш 1:1, очко с раздачи (21 двумя картами) — 3:2, ничья — ставка назад. Без удвоения и разделения.
  Каждая раздача — из свежей колоды. После итога «Ещё раз» — та же ставка.
- Карты выкладываются по одной (сначала твоя, потом дилера), вторая карта дилера вскрывается после «Хватит»;
  рядом с руками — очки, слева — последние итоги.
- **Ворчун** при первом визите ворчливо объясняет правила (щёлкай по нему — дальше), потом ворчит на всё:
  на выигрыш, проигрыш, перебор, ничью и просто если ткнуть в него. «?» — правила ещё раз.
- Ушёл из-за стола (Esc, «В игровую») — несыгранная ставка возвращается, начатая раздача доигрывается «Хватит».
- Картинки (необязательно): `characters/dealer_gnome` (по пояс, 150×150), фон `backgrounds/blackjack`, лист карт
  `icons/cards_sheet` (3.27). Без них всё рисуется кодом.
- F1 → «Блэкджек: правила снова».

# 3.28.3 — все игры на одном столе, Ворчун из картинки, раздача из стопки
- **Откат 3.28.2** (решение пользователя): все игры Игровой — на одном столе (стол рулетки), меняются только
  правила, карты и прочее. Свой фон блэкджека убран (`backgrounds/blackjack` больше не используется).
- **Ворчун** — картинка пользователя `characters/dealer_gnome` (рыжий гном по пояс за столом).
- **Раздача из стопки:** каждая карта вылетает из башмака, по дуге летит рубашкой вверх, ложится со шлепком
  и переворачивается лицом (сужается до ребра и раскрывается). Закрытая карта Ворчуна переворачивается, когда он
  вскрывается после «Хватит». Очки над рукой появляются, когда карта уже открыта. Кнопки ждут, пока карты
  не легли (`CARD_STEP` 0.36 с, `CARD_FLY` 0.26 с, `CARD_FLIP` 0.18 с).
