# Версия 3.39.3 — монетка в пруду не закрывает рыбу

Пользователь 26.11: «монеты закрывают собой рыбу». На участке пруда монетка урожая теперь висит справа вверху
участка (рядом с рыбой, не на ней) и чуть меньше (x0.85). Подписи и полоски соседних участков она не задевает.
На грядках других глав — как было (по центру).
