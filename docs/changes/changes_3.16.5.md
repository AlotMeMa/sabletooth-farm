# Версия 3.16.5 — «failed to create renderer» после 3.16.4

**Что было:** в 3.16.4 полный экран пересоздавался не только после сворачивания, но и при потере/возврате фокуса.
А само пересоздание окна снова дёргает фокус — окно пересоздавалось по кругу, пока Windows не перестал давать
новые (`failed to create renderer`), и сообщение об ошибке сыпалось столбиком.

**Теперь:**
- полный экран пересоздаётся только по настоящему «свернули → развернули», и только если размер окна правда
  стал другим; не чаще 3 раз за игру; фокус, Alt+Tab без сворачивания и клики в другие окна ничего не трогают;
- убрана ежесекундная «страховка» по размеру окна (она тоже могла запускать круг);
- если переключить экран не получилось — игра спокойно остаётся в окне, сообщение одно, а не столбик.
