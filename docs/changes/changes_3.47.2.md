# 3.47.2 — Проверка картинок для драконов, трио «Иней» на сцене

Пользователь залил (27.11): 9 огненных растений, грядки драконов, лист главы 3×3, помощники 2×2, скупщик 1×3,
трио «Иней». Проверено подгонкой (`/tmp`-превью и кадр зала):
- Растения режутся на 3 стадии правильно, мордашки на месте. У светящихся (серные грибы, обсидиановая ягода,
  фрукт феникса, золотой драконий фрукт) нейросеть нарисовала свечение по мадженте — розовый ореол. Добавлена чистка
  `spritefit.dehalo` для `crops/dragons/*`: розоватое, связанное с краем, уходит вместе с фоном (внутри контура —
  щёчки, фиолетовые ягоды — не трогает). Свой ключ кэша (`|dehalo`).
- Грядки, лист главы (саламандра, золотая саламандра, бесёнок сидя/в полёте, значок, монета-чешуя, кнопка праздника,
  работник, танцовщица), помощники и повозки с ящером (слева маленькая → справа большая) — чистые. В игру встанут
  вместе с главой 5 (листы зарегистрирую под имена главы, когда решим её устройство).
- `characters/ice_idols` — трое на сцене, размер как надо.
