# 3.40.1 — Ставки на нескольких улиток

По просьбе пользователя: выбрал улитку → она выделена → кладёшь фишки на неё; выбрал другую → кладёшь на неё.
Фишки остаются на своей улитке, а не переезжают за выбором.

- `SnailRace.bets` — фишки по улиткам; `bet` — сумма на столе; `add_bet` кладёт на выбранную.
- Выигрыш — стопка на пришедшей первой × её коэффициент; остальные стопки остаются у Якоря.
- «Убрать» — снимает фишки с выбранной улитки, а если на ней пусто — со всех.
- «Ещё забег» повторяет все ставки на тех же улитках.
- Внизу: «Выбрана: Молния · на столе 50 (3 улитки)». Правила Якоря переписаны короче, про ставки на нескольких.
- F1 «следующий — победа» ведёт к финишу улитку с самой большой стопкой, «проигрыш» — улитку без фишек.
- Тесты: фишки не переезжают, оплата только стопки победителя, повтор всех ставок.
