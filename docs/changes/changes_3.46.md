# 3.46 — Карта глав из плиток пользователя

- Окно «Переезд»: карта собирается из 5 плиток пользователя `ui/move_map_<глава>` (summer, medieval, winter,
  fishing, dragons). Из квадрата 1024×1024 берётся полоса посередине (518×278 на карте), соседние плитки заходят
  друг на друга на 44 px с плавным проявлением — шов не виден. Кружок главы — на поляне в центре плитки.
- «Тайна» (следующая неоткрытая глава) — плитка драконов под густым туманом.
- Если хоть одной плитки нет — старая карта `ui/move_map` (как раньше). Сценарий — `move_tiles`.
- `backgrounds/dragons` пользователя принят (16:9, игра срежет края по ~6%); проверен под полем 3×3 и скупщиком.
