# Версия 3.36 — заготовка 4-й главы «Рыбацкая деревня» (пока закрыта)

Решения пользователя 25.11 вечером: тема — рыбацкая деревня, рыбы вместо овощей, мокрый серо-синий вайб;
поле — сплошной пруд из 9 участков за сетками, закрытые — болото; автосборщики — рыбаки (**артель**, как крестьяне
и гномы); солнце остаётся; вместо гномьего пришествия — **Рыбацкий фестиваль** (та же логика, ловят рыбаки);
вместо вороны — **чайки**, вместо белки — **краб**; вместо мельницы — рыборазводня (3.37); за уловом приезжает
средневековая повозка с рыбой; валюта — **крючки**; трофей зимы «Снежинка» здесь делает вылов легче (3.38);
здесь откроются скачки улиток (3.39).

- `FARMS[3]` «Рыбацкая деревня» (`ready=False`): рыбы Плотва, Карась, Окунь, Лещ, Карп, Форель, Лосось, Кои,
  Золотая рыбка (`roach … goldfish`), `helpers="fishermen"`, `weather=FISH_FEST`, `crow=True` (чайки),
  `barn="fishery"`, `tree="fishing"`, `cur="hook"`, покупатель — рыботорговец (`vehicle="fishcart"`: Тележка с бочкой,
  Повозка с рыбой, Королевский обоз). Трофей — «Золотой крючок» (для следующей главы).
- `THEME_FISHING`: серо-зелёная мокрая трава, мостки, вода; `pond=True`, `critter="crab"`, `pest="gull"`.
- Рыбацкое дерево (`_fishing_tree`): «Улов» (казна, артель, клёвый день, большая вода), «Рыбацкий фестиваль»,
  «Берег» (крабы и чайки), «Повозка» (коптильня, щедрый рыботорговец). Цены — как у других деревьев.
- Рисунки кодом (`farmgame/art_fishing.py`): рыбы с мордашками, выпрыгивающие из воды; участок пруда — вода
  за сеткой с поплавками и колышками, закрытый — болото с камышом; краб (бежит боком, золотой светится), чайка;
  рыбак (значок артели в жёлтой зюйдвестке, на фестивале — с удочкой у каждого участка, справа двое пляшут с уловом);
  груз повозки — бочки и рыбьи хвосты; крючок — значок валюты; кнопка фестиваля — рыба с флажками.
- «Садки» (кнопка вместо сарая) пока открывают заглушку «Рыборазводня строится».
- Задания таверны в деревне говорят «чаек», «краба», «рыбаков», «рыботорговцу», «Устрой рыбацкий фестиваль».
- Достижение «Покоритель зимы» — именно про Зимнее поле.
- Картинки: `crops/fishing/<рыба>` (полоски 3 стадий), `tiles/fishing/soil(_locked)`, `backgrounds/fishing`,
  листы `icons/fishing_sheet` 3×3 и `vehicles/fishcart_sheet` 1×3 — промпты в доке промптов.
